给同事改源码 — 益佳通标签生成器
================================

这个文件夹是「配方」（源码），不是那个双击就能用的 .exe。
用 Cursor / WorkBuddy 打开这个文件夹，才能让 AI 帮你改规则。


一、怎么打开（给 AI 改）
----------------------
1. 打开 Cursor 或 WorkBuddy
2. 选「打开文件夹」，选中本文件夹「给同事改源码」
3. 在对话框里用中文说你要改什么，例如：
   - 「把卡板从每 12 个内箱改成每 10 个」
   - 「外箱改成每 5 个内箱一组」
4. 让 AI 改完后，再让它帮你测试或重新打包（如果需要 .exe）


二、自己在电脑上试跑（可选）
--------------------------
前提：电脑已安装 Python（运行程序需要的「引擎」）。

1. 打开「命令提示符」或 PowerShell，进入本文件夹
2. 安装依赖（第一次做一次即可）：
   pip install -r requirements.txt
3. 双击「打开标签生成器.bat」，或运行：
   python app.py


三、关键文件（AI / 人主要改这里）
--------------------------------
| 文件 | 作用 |
|------|------|
| label_gen.py | 装箱规则、生成 Excel。卡板几个内箱、外箱几个内箱，都在这里 |
| app.py | 填表窗口、记住上次填写、保存文件 |
| 益佳通标签模板.xlsx | 原来的表格模板，对照用 |
| requirements.txt | 需要安装的库（主要是 openpyxl） |
| 打开标签生成器.bat | 本机有 Python 时双击启动 |


四、最常改的数字（在 label_gen.py 里）
------------------------------------
打开 label_gen.py，大约在文件前部：

  INNER_PER_OUTER = 4          ← 几个内箱合成 1 个外箱
  INNER_PER_PALLET_QR = 12     ← 几个内箱合成 1 张卡板码（当前是 12）

只改这两个数字，一般就能改装箱规则。
改完后要用 python app.py 或 bat 再生成一张表核对。


五、和「发给同事」那个文件夹的区别
--------------------------------
| 文件夹 | 给谁 | 做什么 |
|--------|------|--------|
| 发给同事 | 只会用、不改 | 双击 .exe 生成 Excel |
| 给同事改源码 | 要改规则 | 用 AI / 改代码后再运行 |

两边可以同时发：日常用 .exe；要改规则时打开本文件夹。


六、改完还要给别人「不用装 Python」的版本？
------------------------------------------
跟做过这个工具的人说一声，让他帮你重新打包成 .exe；
或在 Cursor/WorkBuddy 里说：「请帮我重新打包成双击能用的 exe」。
（打包需要本机已装好 Python 和相关工具。）
