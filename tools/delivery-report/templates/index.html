送货单出货报告工具

选择送货单 Excel → 选择各物料编码的 PDF 模板 → 生成报告。
只读取「数据状态 = 已发货」的行。自动改：日期、订单编号、订单数量=交货数量、尺寸 Sample1～10（公差内小幅波动）。其它保持模板原样。

1. 选择送货单明细（Excel）

尚未选择

2. 选择出货报告模板（可一次多选）

请先选择 Excel

模板文件名必须带物料编码（如 3228000410101.pdf），只按文件名匹配，不看 PDF 里旧的客户货号。可按住 Ctrl 一次选多个。

3. 核对物料并勾选要生成的

物料编码
品名
数量合计
采购订单号
模板匹配

仅统计已发货行的「发货数量」合计；订单号取该编码已发货第一行的「采购订单号」。生成前请核对模板文件名。

4. 生成

点击生成后，会弹出窗口让你选择保存文件夹。
